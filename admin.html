Connexion à l'administration

Collez votre clé d'accès GitHub pour gérer les réalisations affichées sur le site.

Sans cette case, la clé est oubliée à la fermeture de l'onglet. Ne la cochez que sur votre propre ordinateur.

Comment créer ma clé d'accès ?
  1. Connectez-vous à GitHub, puis ouvrez la page de création d'une clé (Settings, Developer settings, Personal access tokens, Fine-grained tokens).
  2. Token name : un nom au choix, par exemple « Admin Pixel Designer ».
  3. Expiration : choisissez la durée. À l'expiration, il suffira de créer une nouvelle clé.
  4. Repository access : « Only select repositories », puis le dépôt pixeldesigner.
  5. Permissions, « Repository permissions » : passez Contents sur « Read and write ». Ne changez rien d'autre.
  6. Cliquez sur « Generate token », copiez la clé (elle commence par github_pat_) et collez-la ci-dessus.

Cette clé ne donne accès qu'aux fichiers de ce site. Si vous pensez qu'elle a fuité, supprimez-la sur GitHub : elle cesse aussitôt de fonctionner.
